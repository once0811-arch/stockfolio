# Usability Audit (PM + Investor Lens)

기준일: 2026-03-16

## 왜 못써먹는 품질이었나 (원인)
1. 신뢰 문제
- 상단 핵심 수치가 정적 텍스트여서 실제 원장/포지션과 불일치 가능.
- 투자자는 "숫자를 믿을 수 있는지"부터 확인하므로 이 지점에서 이탈한다.

2. 판단 지연
- Overview가 일부 종목 중심 시야(Top N)로 운영되어 전체 비중/집중 리스크 판단이 늦다.
- 실행 우선순위가 화면에서 제시되지 않아 사용자가 다음 행동을 스스로 계산해야 한다.

3. 실행 마찰
- 거래 등록 후 메모 작성으로 자연스럽게 이어지지 않아 기록 습관이 끊긴다.
- Research는 검증 대기 큐 중심이 아니라 전체 나열이라 처리 우선순위가 약하다.

## 해결 원칙
- KPI 요약 > 경고/상태 > 실행 액션 > 상세 근거 순서 고정
- 전 화면에서 "금융 정보 제공, 투자 자문 아님" 경계 유지
- estimate/actual/target 분리 불변 유지

## 적용된 해결
1. 동적 신뢰 지표
- Layout snapshot을 원장 기반 계산값(USD/KRW, YTD P/L, 검증대기 메모)으로 교체.

2. Overview 재설계
- 전체 보유 비중, 종목별 포지션 테이블, 집중 리스크 경고, 실행 우선순위를 한 화면에 통합.

3. 흐름 마찰 완화
- 거래 저장 직후 해당 거래를 자동 선택해 메모 작성으로 즉시 전환.
- Research에 검증 대기/전체 필터를 추가하고 supporting/contradicting evidence를 상세 노출.

## 잔여 리스크
- in-memory 저장소 특성상 프로세스 재시작 시 데이터 휘발.
- 본 리스크는 MVP 범위에서 허용하되, M4+에서 DB 영속화로 전환 필요.
